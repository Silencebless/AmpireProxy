# Ampire, Flutter-клиент (демо 0.2)

Утилита для подключения к своим серверам. Это интерфейс по утверждённому прототипу: тёмный стиль, круглая кнопка питания, капсулы, плавающая панель из трёх вкладок. Работает в демо-режиме: данные встроены, сеть не используется.

## Что внутри

- Экраны: «Главная», «Мониторинг», «Инструменты» и вложенные «Серверы», «Подписки», «Маршрутизация», «Журнал», «О приложении».
- Серверы открываются со строки текущего сервера на главной. Если подписок несколько, вверху выпадающий список подписок, у каждой свои ноды.
- Шторка добавления подписки: любая ссылка в демо превращается во встроенную подписку.
- Имитация подключения с пульсацией кольца, таймером сеанса и скоростью.
- Токены дизайна в `lib/theme/tokens.dart`, состояние в `lib/state/app_state.dart`.
- Разбор подписок в `lib/core/`: ссылки vless, vmess, trojan, shadowsocks, hysteria2 и tuic, список ссылок открытым текстом или в base64, заголовки Remnawave (трафик, срок, название, интервал обновления, поддержка, объявление) и сборка исходящих соединений sing-box. Ноды с транспортом xhttp помечаются как требующие Xray-core.
- Тесты в `test/`: сценарий на экране, логика подписок и навигации, разбор ссылок и подписок, исходящие соединения sing-box.

## Чего ещё нет

- Настоящего подключения: нужны Go-ядро (sing-box, Xray-core) и нативные VPN-слои платформ.
- Подключения экрана добавления к разбору: скачивание подписки по ссылке и передача идентификатора устройства для лимитов Remnawave (формат заголовков сверим с документацией панели), ссылки `ampire://`.
- Разбора JSON-подписок, полного конфига sing-box (маршрутизация, DNS, TUN) и конфига Xray-core: их формат зависит от версии подключаемого ядра.
- Шрифта Onest: положите файлы в `assets/fonts` и раскомментируйте блок `fonts` в `pubspec.yaml`.
- Раскладки для десктопа: пока контент держится в колонке шириной до 480.
- Локализации: тексты на русском зашиты в код.

## Как собрать

**Через GitHub, без установки Flutter у себя.** Создайте репозиторий, загрузите в него содержимое этой папки. Вкладка Actions → workflow `build` соберёт Android (APK), Windows, Linux, macOS и iOS без подписи. Результаты лежат в артефактах запуска.

**Локально.** Нужен Flutter 3.27.4:

```sh
sh tool/bootstrap.sh     # создаёт папки платформ
flutter pub get
flutter test
flutter run              # выберите устройство или desktop
```

Папки платформ (`android`, `ios`, `macos`, `windows`, `linux`) в репозитории не хранятся: их создаёт `tool/bootstrap.sh`. Когда добавим нативный код VPN, их придётся закоммитить и убрать из `.gitignore`.

## Важно

Код написан без компилятора (в среде автора нет Flutter), проверен только на баланс скобок и ссылки между файлами. Первый запуск CI может показать ошибки сборки. Пришлите лог, и я их исправлю.
